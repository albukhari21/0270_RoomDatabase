# Praktikum 9 - Room Database

Aplikasi Android berbasis **Jetpack Compose** dengan arsitektur **MVVM** dan penyimpanan lokal **Room Database** untuk mengelola data siswa (menampilkan daftar siswa dan menambah data siswa baru).

## Fitur Utama
- Menampilkan daftar siswa yang tersimpan di database lokal (`Room`).
- Menambahkan data siswa baru (Nama, Alamat, dan Nomor Telepon) dengan validasi input.
- Navigasi antar layar menggunakan Jetpack Compose Navigation.
